# Sito psicologia Astro

Base statica Astro pronta per GitHub e Cloudflare.

## Avvio locale
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

La cartella generata è `dist/`.

## Personalizzazione
Sostituisci i testi segnaposto in:
- `src/pages/index.astro`
- `src/layouts/BaseLayout.astro`

Le sezioni principali sono:
Home · Chi sono · Ambiti di intervento · Tematiche · Contatti
